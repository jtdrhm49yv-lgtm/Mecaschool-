Connecter la plateforme à Firebase

Cette page est vide tant qu'elle n'est pas reliée à ton projet Firebase (tu peux réutiliser le projet MécaSchool).

  1. Console Firebase → ⚙️ Paramètres du projet → « Vos applications » → application Web → copier l'objet firebaseConfig.
  2. Ouvrir ce fichier HTML et coller les valeurs dans le bloc FIREBASE_CONFIG tout en haut du script (repère 🔧).
  3. Firebase → Authentication → Méthodes de connexion → activer Anonyme.
  4. Firestore → Règles → coller les règles fournies en commentaire au même endroit du script.
  5. Redéployer sur GitHub Pages. C'est tout.
